# Dashboard-Pro
Um painel financeiro interativo que centraliza o registro de receitas e despesas de uma empresa ou projeto, permitindo visualizar a evolução do caixa, identificar os maiores gargalos de gastos e acompanhar o resultado operacional mês a mês.

DISCLAIMER: O banco de dados usado na tabela de Lançamentos foi gerado utilizando Chat GPT-5.6 Luna em modo "Think", portanto os dados de transações não condizem a de nenhuma empresa real.
